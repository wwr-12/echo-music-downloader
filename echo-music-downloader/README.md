为 [EchoMusic](https://github.com/hoowhoami/EchoMusic)（`>= 2.3.2-beta.10`）补充**本地音乐下载**能力的社区插件：右键任意歌曲即可下载，自动落到**这首歌真实支持的最高音质**，并可将歌词、封面与歌曲信息**直接嵌入音频文件**，在任何播放器、车机、手机上完整显示。

## ✨ 功能

| 功能 | 说明 |
|------|------|
| 歌曲右键下载 | 任意歌曲列表右键 →「下载歌曲」，按设置的默认音质下载 |
| 下载当前歌曲 | 「下载管理」页一键下载正在播放的歌曲 |
| 最高可用音质 | 自动落到歌曲实际支持的最高音质，绝不冒充交付（见「音质决策机制」） |
| 下载管理 | 进度条、实时速度、暂停 / 恢复 / 重试 / 取消、「刮削自检」一键诊断 |
| 下载历史恢复 | 重启应用后自动从宿主记录恢复已完成的下载条目 |
| 音质选择 | 标准 128K / HQ 320K / SQ 无损 / Hi-Res / 蝰蛇母带 / 蝰蛇超清 / 蝰蛇全景声 |
| 文件命名模板 | 默认 `{artist} - {title}`，支持 `{title}` `{artist}` `{album}` `{quality}` 变量 |
| 同名冲突策略 | 自动重命名 / 覆盖 / 跳过；重复下载同一首歌自动生成 (1) 后缀 |
| 音乐刮削 | 标题 / 歌手 / 专辑 / 歌词 / 封面嵌入音频文件，或生成伴生文件（可配置） |
| 主题自适应 | 界面随宿主明暗主题与彩色壁纸自动适配，不再出现白底白字 |

## 🎚️ 音质决策机制

下载音质不是"选什么给什么"，而是**"最多给到选的，且给的一定是真的"**：

1. **候选链**：以你选的音质为上限，按宿主同款档位顺序从高到低逐级尝试
   `128 → 320 → 无损 → Hi-Res → 蝰蛇超清 → 蝰蛇母带 → 蝰蛇全景声`
2. **音源核对**：每档先在歌曲的音质清单（relateGoods）里核对真实音源（支持 `hq`/`sq`/`hires` 别名与 level 位图），清单里没有的档位直接跳过——**绝不拿标准音质的 hash 冒充高音质请求**
3. **真实性校验**：酷狗接口对无权限的高音质请求有时会**静默降级**（不报错、直接返回一个标准 mp3 直链）。插件对无损档校验文件容器（必须 flac/ape/wav）、对 HQ 校验码率——**降级的假音源会被拦截**，继续沿链下降
4. **如实交付**：toast 与文件名中的音质永远反映真实下载内容，例如：「无法获取 蝰蛇全景声，已回退到 SQ 无损」→ 拿到的就是 18M 的 `.flac`，而不是 3M 的 `.mp3`
5. **终极兜底**：候选链全部失败（如账号无任何 VIP 权限）时，用默认音源尽量完成下载

## 📦 安装

### 方式一：插件源（推荐）

在 EchoMusic「插件市场 → 添加源」中填入：

```
https://raw.githubusercontent.com/Apricityx/echo-music-downloader/main/echo-plugins.json
```

> 直连 GitHub 受限时，可在地址前加加速前缀，例如 `https://gh-proxy.com/` + 上述地址。

### 方式二：本地安装

1. 下载最新的 `echo-music-downloader-v2.3.1.zip`
2. 打开 EchoMusic →「插件管理」→「本地插件」→ 加载该 zip
3. 启用插件

## 🚀 快速开始

1. 首次下载会弹出系统目录选择器，选择音乐保存目录（授权持久保存，失效可在设置中重新授权）。
2. **首次嵌入会弹出授权确认框**——这是宿主对插件内置原生工具的安全机制，点「允许」后按插件版本 + 工具哈希记住授权。**刮削开启且为嵌入模式时，未授权将无法下载**；也可以改用「伴生文件」模式，无需授权。
3. 拿不准刮削链路时，到「下载管理 → 刮削自检」一键诊断：目录授权、嵌入工具授权、当前歌曲歌词 / 封面可用性逐行显示。

## ⚙️ 设置项

| 设置 | 可选值 | 说明 |
|------|--------|------|
| 下载音质 | 128K / HQ / SQ / Hi-Res / 蝰蛇三档 | 目标音质上限，自动落到真实最高可用 |
| 下载目录 | 系统目录选择器 | 持久化授权，可重新授权 |
| 命名模板 | `{artist} - {title}` 等 | 支持标题 / 歌手 / 专辑 / 音质变量 |
| 冲突策略 | 重命名 / 覆盖 / 跳过 | 同名文件处理方式 |
| 音乐刮削 | 开 / 关 | 总开关 |
| 写入方式 | 嵌入音频 / 伴生文件 / 两者都写 | 嵌入需要授权原生工具 |
| 刮削歌词 / 封面 / 信息 | 开 / 关 | 三项可独立开关 |
| 音质自动回退 | 开 / 关 | 关闭后仅尝试所选音质，失败即报错 |

## 🎵 音乐刮削与元数据嵌入

写入方式三选一：

| 写入方式 | 行为 |
|----------|------|
| 嵌入音频文件（默认） | 元数据直接写进音频标签，任何播放器都能识别 |
| 伴生文件 | 生成 `歌曲名.lrc` / `歌曲名.jpg` / `歌曲名.json` |
| 两者都写 | 嵌入 + 伴生文件 |

嵌入由插件内置本机工具 `native/echotag-x64.exe` 完成（Rust 编写、仅标准库、约 144 KB）：

- **MP3** → ID3v2.3：`TIT2` / `TPE1` / `TALB`（UTF-16 中文）+ `USLT` 歌词 + `APIC` 封面；自动剥离旧 ID3v2.4 / v1 标签
- **FLAC** → `VORBIS_COMMENT` + `PICTURE` 块；**合并式打标**：
  - 新值只覆盖 TITLE / ARTIST / ALBUM / LYRICS 五个键，其他播放器或第三方工具写入的字段**原样保留**
  - 未提供新封面时**保留原有 PICTURE 封面块**
- 临时文件写入 → 原子替换，8 MB+ 大文件安全；嵌入成功后自动清理全部临时文件与其宿主任务记录
- 封面在**真正落盘后**才启动嵌入工具；封面下载失败时自动降级为仅嵌歌词
- 非 Windows 平台、授权被拒绝或嵌入超时，自动回退为伴生文件并明确提示原因

## 🎨 主题自适应

插件界面（下载管理页 / 设置面板）跟随宿主主题：

- 文字使用宿主标准文字变量，明暗主题自动切换
- 面板与卡片使用中性半透明背景——浅色主题呈浅灰、深色或彩色壁纸主题呈微亮玻璃层
- 错误 / 警告提示使用宿主状态色，深浅主题下都保持可读

## 🛠 从源码构建

echotag 工具源码位于 `echotag-src/`（纯 Rust 标准库，无第三方依赖）：


构建产物 `target/release/echotag.exe` 复制为插件的 `native/echotag-x64.exe` 即可。

## ❓ FAQ

**Q：为什么下载的文件和我选的音质不一样？**
插件只会"降级"不会"冒充"：你选的音质这首歌没有真实音源（或账号无权限）时，会自动落到**实际支持的最高音质**，并在 toast 里如实说明。接口静默降级返回的假音源（选无损却给 mp3）会被拦截。

**Q：提示「嵌入工具未授权，已取消本次下载」？**
宿主安全机制要求运行插件自带的原生工具前必须获得你的一次性确认。重新下载并在弹窗中点「允许」即可；或到「下载管理 → 刮削自检」主动触发授权。不希望授权的话，把刮削写入方式改为「伴生文件」。

**Q：插件升级后为什么又要授权一次？**
授权与插件版本 + 工具哈希绑定，属预期行为，点一次「允许」即可。

**Q：重复下载同一首歌会怎样？**
按冲突策略处理：默认自动重命名生成 `(1)` 后缀；「跳过」策略会提示已存在；「覆盖」策略替换旧文件。

**Q：下载后文件去哪了？**
保存在你选择的下载目录。「下载管理」页会恢复历史记录，文件被手动删除后重新下载也能自愈，无需手动清理记录。

**Q：哪些格式支持嵌入？**
MP3（ID3v2.3）与 FLAC（Vorbis Comment + PICTURE），工具按文件魔数识别、不依赖扩展名。其他格式（M4A / OGG 等）自动回退为伴生文件。

**Q：VIP / 无损音质下载失败？**
付费音质需要账号有对应权限，无权限时按候选链自动降级到真实可用的最高音质。

## 🔒 隐私与安全

- 播放直链与歌词 / 封面均来自酷狗官方接口（与宿主播放器同一授权链路），**不经过任何中转服务器**
- 嵌入工具仅在本机运行，只读写你指定的音频与临时文件
- 授权绑定插件版本 + 工具二进制哈希，工具被替换后授权自动失效

## 平台兼容性

嵌入工具目前仅提供 Windows x64 版本（`echotag-x64.exe`）。非 Windows 平台上插件可正常下载与生成伴生文件，嵌入自动跳过。
